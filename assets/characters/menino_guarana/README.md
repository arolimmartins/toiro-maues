# Menino Guaraná - Sprites

Pacote organizado a partir da folha de referência do personagem.
Cada pasta contém os frames PNG numerados e cada animação também possui um spritesheet horizontal.

Animações: idle, walk_right, walk_left, walk_front, walk_back, run_right, run_left, jump, collect, lift_basket, collect_happy, sad, angry, surprise, hurt, death, victory.

Observação: os frames foram recortados automaticamente da folha de referência. Revise os recortes antes de usar em produção, especialmente nas animações com poses maiores.
